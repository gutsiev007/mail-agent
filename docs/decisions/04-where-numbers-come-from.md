# 04. Откуда берутся номера

**До (wf2).** Если поле номера пустое, workflow искал номер в `summary` модели. Письмо «Когда придёт оборудование?» с `summary="Когда доставят O-52?"` давало пересылку по O-52: номер, которого клиент не называл.

**Выбор: A.** Номер берётся только регулярным выражением из темы, тела и переписки. Номер из ответа модели принимается, только если он есть в этом тексте; иначе отбрасывается (`_dropped_by_code` в трассе). Если в тексте ровно один номер нужного вида, код подставляет его сам.

**Что дороже.** Пересылка не по тому заказу дороже лишнего уточнения: исполнитель работает над чужим заказом, клиент ждёт ответа не по своему вопросу. Вариант C («у клиента один заказ — значит, он») — угадывание. На отложенном наборе есть письмо `hold-06`, автор которого ожидает именно такого угадывания: по нашему решению оно получит уточнение и будет засчитано как ошибка. Это известная цена решения.

**Какие письма dev ухудшатся.** Ни одно: во всех письмах dev с номером он есть в тексте (`mail-10` — «Когда отгрузите O-52?»). Тест `test_number_in_body_still_used`.

**Тест.** `NumbersTest`, `AcceptanceTest` п. 5.
