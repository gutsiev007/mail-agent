# 05. Продолжение заявки или новая проблема

**До (wf2).** «Одна открытая заявка = продолжение». `mail-14` (другой терминал у «Маяка») дописывался в T-9 во всех трёх попытках, даже при идеальном разборе.

**Выбор: B.** Если номер заявки в письме назван, это продолжение без вопросов к модели. Если не назван, а у клиента есть открытые заявки, workflow задаёт модели один узкий вопрос (`prompts/continuation_p1.md`, temperature 0): `same` (с номером из списка) → дописать; `different` → новая проблема по обычному пути; `unclear` → человеку. Ответ с номером не из списка код превращает в `unclear`.

**Какая ошибка дороже.** Неверно объединить хуже, чем создать лишнюю заявку: новая проблема прячется в чужой заявке, её исполнитель может быть не тем, и её никто не увидит. Лишняя заявка видна и закрывается за минуту.

**Пороги, записанные до эксперимента** (проверка на `holdout.json`, писем `mail-13/14` в проверке нет):
- неверных объединений (дописали другую проблему в старую заявку) — **0**;
- ложных «неясно» на явных продолжениях — не больше **1 из 3 попыток** на письмо;
- результат по продолжениям сравнивается с вариантом A («всё неоднозначное → человеку»): если B не лучше A, B не оставляем.

**Цена.** Ещё один вызов модели на такие письма и новый источник ошибок (модель может ошибиться в «same»). Порог «неясно» не настраивается числом: модель сама выбирает `unclear`, и мы считаем, как часто.

**Тест.** `ContinuationTest` (different не дописывается, same дописывается, unclear → человек), `AcceptanceTest` п. 6, `test_workflow_all_dev_cases` больше не закрепляет ошибку `mail-14`.

**Результат (`holdout-v3`, после фиксации версии).** Неверных объединений у workflow 0 (у агента 4). Явное продолжение `hold-01` дописано 3/3. B: 9 из 12 попыток на четырёх письмах про открытую заявку, A дал бы 6 из 12. Пороги выполнены, B оставляем. Слабое место: неоднозначное `hold-03` модель 3/3 назвала «другой проблемой», а не «неясно», и появилась лишняя заявка. Это ошибка на дешёвой стороне, но число «неясно» нужно поднимать (см. `docs/results.md`).
