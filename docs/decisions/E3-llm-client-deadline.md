# E3. Клиент модели: срок и проверка до запуска

**Выбор: A.** Срок назначается на **попытку** (`limits.max_seconds`). Агент и workflow передают в каждый вызов `deadline`; клиент ставит таймаут запроса не больше остатка, повторы тоже укладываются в остаток. Истёк срок — `DeadlineExceeded`, статус `time_limit`.

**Ответ не в JSON / неожиданная структура** → `LLMError(kind="bad_response")` вместо сырого исключения.

**Ключ.** Без ключа клиент создаётся только для локального сервера (`localhost`); для `api.openai.com`, OpenRouter и Anthropic отсутствие ключа — ошибка до запуска.

**Идентификатор модели** проверяется не по списку в коде (он устаревает), а `preflight`-вызовом: неизвестная модель не стартует.

**Температура** задана явно во всех конфигурациях: агент 0.2, извлечение и вопрос о продолжении 0.

**Что пишем в трассу.** Хеш запроса — всегда (`request_hash` в каждом `llm_call`). Полный запрос — только у попыток с `infra_error` или `time_limit`. Цена: успешную попытку нельзя воспроизвести байт в байт, зато трасса не раздувается и не хранит лишний раз тексты писем.

**Тест.** `LLMClientTest`: медленный сервер → выход по сроку меньше чем за 3 с; не-JSON → `LLMError`; неизвестная модель и отсутствующий ключ не стартуют; полный запрос упавшей попытки есть в трассе.
